# PixelAnimator

PixelAnimator 是一个使用 C++、SDL3、OpenGL 与 Dear ImGui 开发的像素动画编辑器，目标是为像素游戏素材制作提供轻量、清晰、可扩展的绘制与动画工作流。

项目目前仍在开发中，已经具备基础绘制、选区、图层、时间轴、洋葱皮、PNG 导入导出与项目保存等能力。

## 功能概览

- 像素画布编辑：支持新建项目、缩放、平移、网格、棋盘格透明背景。
- 绘图工具：画笔、橡皮擦、油漆桶、吸管、直线、曲线。
- 图形工具：矩形描边、填充矩形、椭圆/圆描边、填充椭圆/圆。
- 选区工具：矩形选区、椭圆选区、魔棒、自由套索、多边形套索。
- 选区变换：支持选区移动、八手柄缩放、蚂蚁线、非破坏性拖拽预览。
- 对称绘制：支持左右对称、上下对称开关，并可复用常用绘制工具。
- 图层系统：支持新建、删除、重命名、显示/隐藏、锁定、透明度、排序。
- 图层合并：支持多选连续图层后合并，或合并为新图层并保留原图层。
- 时间轴：支持多帧动画、播放、FPS 设置、帧选择、帧分组。
- 分组播放：当前帧位于分组中时，播放范围可限制在该组内。
- 洋葱皮：支持显示前后帧，可选择使用方向颜色或保留原帧颜色并降低透明度。
- 导入导出：支持 PNG 单帧导入/导出、精灵图导入/导出。
- 项目格式：支持二进制 `.pxanim` 与 JSON `.pxanim.json`。
- 撤销重做：支持 Undo/Redo 与历史记录面板。

## 技术栈

- 语言：C++17
- UI：Dear ImGui
- 窗口与输入：SDL3
- 图片读写：SDL3_image
- 渲染：OpenGL
- 构建：CMake

## 目录结构

```text
src/
  app/       应用总控层，负责主循环、菜单回调、项目会话、快捷键、导入导出流程
  assets/    工具栏、图层、播放、对称、精灵图导出等图标资源
  commands/  独立编辑命令，例如删除、复制粘贴、旋转、翻转
  core/      核心数据结构，例如 Project、AppContext、帧、图层、选区、撤销历史
  io/        文件读写，例如项目序列化、PNG 导入导出
  render/    渲染辅助，例如纹理封装、画布纹理、选区蚂蚁线和手柄绘制
  tools/     绘图与选区工具，例如画笔、填充、直线、曲线、圆形、框选
  ui/        ImGui 界面层，例如菜单、项目窗口、时间轴、图层面板、调色板
  main.cpp   程序入口
```

## 构建方式

### 环境要求

- Windows
- CMake 3.15 或更高版本
- 支持 C++17 的编译器
- OpenGL 环境

仓库中已经包含项目当前使用的 `include/`、`lib/` 与 `imgui/` 目录。CMake 会在构建时将 `SDL3.dll` 与 `SDL3_image.dll` 复制到构建输出目录。

### 构建命令

在项目根目录执行：

```powershell
cmake -S . -B build
cmake --build build
```

构建完成后运行：

```powershell
.\build\PixelAnimator.exe
```

如果使用 Visual Studio 生成器，也可以打开 `build/PixelAnimator.sln` 后编译运行。

## 基本使用

1. 启动程序后通过 `File -> New...` 创建项目。
2. 在左侧工具栏选择画笔、橡皮、填充、选区、直线、曲线或图形工具。
3. 在画布区域绘制像素内容。
4. 使用时间轴管理动画帧。
5. 使用右侧图层面板管理图层。
6. 使用 `File -> Save` 保存项目。
7. 使用 `File -> Export -> Current Frame (PNG)...` 或 `Sprite Sheet (PNG)...` 导出游戏素材。

## 项目格式

### `.pxanim`

二进制项目格式，适合日常保存与打开。

当前版本会保存：

- 项目名称
- 画布尺寸
- 帧数据
- 多图层像素
- 图层名称、可见性、锁定状态、透明度
- 当前活动图层
- 时间轴帧分组

### `.pxanim.json`

JSON 项目格式，适合调试、查看结构或后续扩展。

JSON 格式更便于人工阅读，但体积通常比二进制格式更大。

## PNG 导入导出

项目使用 PNG 作为主要素材交换格式，因为 PNG 适合像素游戏素材：

- 无损压缩，不会破坏像素边缘。
- 支持 Alpha 透明通道。
- 被常见游戏引擎和美术工具广泛支持。
- 适合角色、道具、UI 图标和 Sprite Sheet。

PNG 相关实现位于：

- `src/io/ImageImporter.cpp`
- `src/io/ImageExporter.cpp`

## 设计说明

### 模块划分

项目采用相对清晰的分层：

- `core` 负责数据。
- `tools` 负责像素编辑算法。
- `commands` 负责可复用编辑命令。
- `io` 负责文件格式。
- `render` 负责渲染辅助。
- `ui` 负责 ImGui 界面。
- `app` 负责把各模块串起来。

### 非破坏性选区变换

选区移动和缩放时会先保存拖拽开始时的像素快照与选区 mask。拖拽预览每一帧都从这个快照重新计算，而不是基于上一帧预览继续变换。

这样可以避免：

- 移动过程产生累计误差。
- 缩放过程反复采样导致像素劣化。
- 拖拽时产生大量撤销点。

相关实现：

- `src/tools/RectSelectionTool.cpp`
- `src/tools/selection/SelectionTransform.cpp`

### 曲线工具

曲线工具使用三阶段交互：

- 拖拽确定起点和终点。
- 调整第一个弯。
- 调整第二个弯并提交。

曲线渲染使用自适应三次贝塞尔细分，再用 Bresenham 线段连接采样点，以获得更稳定的像素曲线。

相关实现：

- `src/tools/CurveTool.cpp`
- `src/tools/CurveTool.h`

### 大画布性能优化

画布渲染使用纹理缓存，避免在内容没有变化时每帧重新合成整张画布并上传纹理。洋葱皮也会先合成为半透明纹理，再一次性绘制，避免大画布下提交大量 ImGui 矩形。

相关实现：

- `src/ui/windows/ProjectWindow_Canvas.cpp`
- `src/render/CanvasTexture.cpp`

## 推荐画布尺寸

PixelAnimator 面向像素游戏素材制作，通常不需要特别大的画布。

常见建议：

- `16x16`：道具、小图标
- `24x24` / `32x32`：角色、敌人、物品
- `48x48` / `64x64`：较大角色、特效
- `128x128`：大型单位、头像、UI 图标
- `256x256`：大图块、场景素材
- `512x512`：偏大的像素图或特殊素材

如果需要制作大场景，建议使用 tilemap 或 Sprite Sheet 方式拆分管理。
